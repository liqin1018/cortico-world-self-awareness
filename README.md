# 自我意识

**她自己的内在时间线。** 没人说话的时候，她也在想自己的事。

这个插件不产生任何消息，也不往对话里塞 token——它只是让她有一个「你不在的时候」：会想起旧事，会走神，会反复琢磨一件没想明白的事。想到的写在本机一个文件里。

---

## 先说清楚：这不是自我意识

**没有主观体验，没有真正的「想要」，每一轮推理都是冷启动。**

它做的是三件可以验证的事：

1. **自主节奏** —— 什么时候想、想多久一次，由上一次想的内容算出来，不是定时器
2. **连续的内在活动** —— 你不说话时她也在动，不是只在你开口时才存在
3. **可追溯** —— 想过什么，文件里一条条都在，你能翻

如果这三件对你来说够了，这个插件就有用。如果你要的是「她真的有感觉」，那做不到，谁做的都做不到。

---

## 它怎么决定什么时候想

不是「每 30 分钟一次」。是：

```
这次想得多、想得深  →  歇久一点
这次敷衍了一句      →  过一会儿再想
```

具体算法在 `src/pool.ts` 的 `density()` 和 `nextGapMinutes()`：

- 密度 = 长度（45%）+ 重要度（40%）+ 有没有抓住具体的东西（15%）
- 间隔 = 下限 + (上限-下限) × 密度，再加 ±12% 抖动

所以两次思考的间隔是不规则的，但每次都有来源。

**更准确地说：间隔现在由她自己定。**

她每想完一件事，可以给自己留一句「下次从哪儿接着想」和一个大致间隔（15 分钟到 6 小时）。
下次思考时，那句话会原样递回到她眼前。她没留，才按上面的密度算。

**她也可以说不想了。** 写一个 `rest`，就按她给的时长歇着（最短 2 小时，最长一天；没给时间默认 8 小时），
时间线上会标一句「她先搁着了」。这不是卡住，是她自己叫停。
留的那句话也不再硬性 12 小时过期：她留得越久，便签存得越久（最多 36 小时）。

**隔夜的事能接着想。** 两小时内的上一条，她有三成概率往下接；如果上一条她自己留了话（或说要歇着），
接续窗口放宽到 20 小时——第二天早上可以接着昨晚那句说第二层，而不是从头再讲一遍。
但同一条线最多接两跳，第三跳强制换题：**不设上限就会变成反刍**，一件不痛快的事每天醒来嚼一遍，比忘掉更糟。

于是会出现这种连续：

```
23:33  那戒指还在怀里揣着，烫不烫啊…
       留给自己：天亮了还惦记着，就看看戒指到底烫不烫

01:23  那晚第四遍猛鬼街…到现在还惦记着
       下次 300 分钟后再想
```

**例外是有人在说话。** 对方说完话后的 20 分钟里她不会去想事——人在聊天时，她该在听，不是走神。这个时长可以调，填 0 关掉。

## 五种方式，她自己挑

| 模式 | 她在干什么 |
|---|---|
| `reflect` | 想起一件旧事，回头看它 |
| `wonder` | 手上没做事，脑子飘走了 |
| `plan` | 想接下来要做什么（不是任务清单） |
| `doubt` | 有件事一直没想明白，再想一次 |
| `synthesize` | 把两件看着不相干的事连起来看 |

**方式不是插件派的。** 每次会把五种摆出来，插件只给一个建议（「这会儿更像走神」），
她自己要换就在 `mode` 里写。她要接着上一条往下想时，才不摆菜单，直接让她说新的一层。

---

## 她会想说话，但不由她开口

对方安静 4–45 分钟后，如果她最近 3 小时里有一条重要度 6 以上的想法，就写一条 `urges.jsonl`：
「我刚才在想……，他已经 10 分钟没说话了」。每段沉默只写一条；她说了「先搁着」的那 12 小时里不写。

插件本身仍然不发消息。记忆核心 0.22.0 会读到这份冲动，决定要不要替她开口——
所以「怎么突然不说话了」这句话，是主模型说的，不是这个插件伪造的。

## 手上挂着几条线

最近 12 条里留过话、还没过期的，最多三条会摆进提示词。她用 `pick` 选接哪条（0 = 新起一件），
接上的那条会带上「多久前写的」，跨夜也成立。

## 配置

装好后**默认是关的**。先去设置页填模型。

### 常见填法

**用 DeepSeek（最省事）**

| 项 | 填什么 |
|---|---|
| 用哪家 | `deepseek` |
| 密钥 | 你的 key |
| 模型 | 留空 |

**用 OpenCode Go（跟编码共用一份额度）**

| 项 | 填什么 |
|---|---|
| 用哪家 | `opencode-go` |
| 密钥 | OpenCode 的 key |
| 模型 | 留空（`deepseek-v4.1-flash`），或模型表里的裸 id |

Go 是 OpenCode 的编码套餐，这里每次思考都算进同一份额度。名字带 `-free` 的免费档模型
只允许 OpenCode 官方客户端调用，第三方客户端会收到 403。

**用本地 Ollama（不花钱）**

| 项 | 填什么 |
|---|---|
| 用哪家 | `ollama` |
| 密钥 | 留空 |
| 模型 | `qwen2.5:7b`（或你本地有的） |

**用别的服务（OpenAI 兼容即可）**

| 项 | 填什么 |
|---|---|
| 用哪家 | `custom` |
| 接口地址 | `https://你的服务/v1` |
| 模型 | 服务里那个模型名 |

### 要花钱的几项

| 项 | 默认 | 说明 |
|---|---|---|
| 一天最多想几次 | 12 | 硬上限，到顶就停到明天 |
| 一天最多花多少 token | 60,000 | 12 次思考大约就是这个量 |
| 一次最多写多少字 | 220 | 按 token 算，太长会变成作文 |

**按 DeepSeek 的价格，一天 12 次大约几毛钱。** 用本地模型是 0。

## 看她的时间线

插件会开一个只在本机的小网页（默认 `http://127.0.0.1:7802`，被占用会自动往后找）。
在 World 页点「看她的时间线」就能打开。

- 按时间倒序，每条标：时间、方式（回看 / 走神 / 打算 / 琢磨 / 综合）、时段、当时的精力、重要度点
- 接着上次想下去的会单独标出来
- 底部是「她对自己的看法」——几条碎念攒够重要度后自动收成的一句
- 顶部：今天几次、花了多少 token、下次什么时候、现在是**在跑 / 睡着了 / 出错 / 已关闭**
- 一个「测接口」按钮：点一下就知道模型配得对不对，不用等她想第一件事

只绑 `127.0.0.1`，不对外，也没有写操作。

## 想过的东西在哪

```
<宿主数据目录>/self-awareness/
  thoughts.jsonl      每条想法一行
  reflections.jsonl   想多了之后抽象出来的自我认知
  state.json          今天的次数、token、下次什么时候想
```

`thoughts.jsonl` 一行长这样：

```json
{"id":"a1b2c3d4","ts":"2026-11-15T14:20:00.000Z","mode":"doubt","text":"他那句「随便」到底是什么意思，还是我想多了","importance":6,"seeds":["8e17dfbc"],"promptTokens":1180,"outputTokens":42}
```

**这个文件可以直接看，也可以删。** 删掉不影响任何东西。

## 和记忆核心的关系

**它是记忆核心的下游消费者，不是替代品。**

```
记忆核心  记得住：卡片 / 召回 / 治理
自我意识  活着：自己的时间线、走神、反复想
```

- 它**读**记忆核心的 `cards.jsonl` 和 `state.json`（只读，从不修改）
- 记忆核心**读**它的 `thoughts.jsonl`：对方开口时带一条进来，优先挑和这句话沾边的，6 小时以外的不要，同一条只推一次

所以想过的东西不会白想——它会在下一次对话里出现，但**不占每轮的常驻 token**，只在真有想法时多约 25。」

---

## 它做不到的

| 想要 | 现状 |
|---|---|
| 让她主动发消息 | ❌ 这是记忆核心的「主动开口」在管 |
| 想完立刻影响下一句话 | ❌ 一期没接，想法还没进对话 |
| 睡着时也做梦 | ❌ 读取记忆核心的状态，判定睡着就完全停 |
| 真正的自我意识 | ❌ 见开头 |
